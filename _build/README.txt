Generator for "Electrical Load Design Report.xlsx" (Node.js + exceljs 4.4.0).
  npm install exceljs@4.4.0
  node assemble.js      (joins the section files into build_full.js)
  node build_full.js    (writes the workbook one folder up)
Recalculate in Excel after building (the file is set to full-calc on open).
